## 1. 目标与范围

- 为高中班级 Windows 10 希沃大屏自动留存教学资料，避免 C 盘还原和 U 盘移除导致资料不可获取。
- Windows 11 本机先迭代，学校最后确认部署、触屏、预览和持久化环境。
- 只考虑 WPS/WPS 图片入口打开的 Word、PPT、Excel、图片和 PDF；Excel 功能保留，但当前不强制补测。
- 第一版优先基本收纳、复制和真实数据链路；背景图片和附属个性化后置。
- **完全只用中文，不做 i18n 或多语言体系。** 不引入 vue-i18n、intl-messageformat、语言包、翻译 Provider 或语言设置。复用组件中的翻译调用改为静态中文文案或普通字符串，保留原视觉与交互。
- 不做账号、云同步、AI/OCR、内容全文索引、联网遥测、手机 MTP、其他系统适配、默认文件管理器或预览替换。

## 2. 视觉与复用

- Celestial Launcher 是最高优先级的组件、主题、布局和交互参考，用户提供的两张截图是实际视觉基准。
- 使用其 customdark、色相 38；沿用暖金强调、深色 surface 层级、圆角、边框、文字、间距和控件行为，不另创设计语言。
- 从原项目复制所需通用组件及依赖；允许修改导入、文案、业务接口和必要的触屏/多选适配，不用近似自制控件替代现成原组件。
- 课程卡片等新业务视图由原 Card、Button、Input、Checkbox、Modal 等组合。
- 复用原导航与窗口操作、TabbedModal/NewModal 设置结构。2026-11-15使用用户提供的 CelesVault 正式图标（应用/托盘/安装器/浏览器），左上角不放图标，只显示文字 CelesVault。
- 保持原视觉密度，扩大必要命中区域并提供缩放；设置合适的最小窗口尺寸。
- 文件名单独最多两行，超长省略。第一版不做自定义键盘快捷键；基本焦点/可访问语义仍保留。
- 代码按适用 GPLv3 条件复用与分发，保留来源、版权、许可及对应源码义务。
- Sigma 仅参考目录读取、复制任务/冲突/取消、目录更新及部分拖拽逻辑，不带入视觉、LAN、终端、压缩管理和扩展系统。
- ClassIsland 仅参考时间表与课表编辑结构，不引入 Avalonia/.NET 应用依赖。

## 3. 应用外壳与运行

- 顶栏和左侧栏持续存在，连接为 Celestial 风格的完整外壳。
- 顶栏：仅应用名文字 CelesVault、全局库文件搜索、仅主页显示方向切换、最小化/最大化还原/关闭。
- 左栏：主页、库、分隔线、每个本地驱动器和外接设备入口、底部设置。
- 第一版整个应用以管理员权限运行；不是已经决定安装独立服务。保留后续拆分可能，外部拖拽第一版不保证。
- 关闭按钮隐藏到托盘且监测继续；托盘提供打开、暂停、退出。
- 正常收纳安静；故障改变托盘图标颜色，不弹窗抢焦点。状态详情仍可通过界面/托盘菜单主动查看。
- 自启动属于待确认的部署条件，见第 10 节；不在开发电脑未经确认注册启动项。

## 4. 持久数据与收纳

- 便携程序放 D 盘，D 盘确认不受冰点还原影响。
- 默认持久根可采用 EXE 同级 data；首次目录选择器默认指向此处并允许修改。正式目录仍由用户选择。
- 资料、索引/数据库、课表、监测规则、固定夹和必要 UI 状态统一放持久根；浏览器 localStorage 不能是关键数据唯一来源。
- 资料实体按日期/课次保存，尽量保留原文件名；同名不同内容不覆盖。
- 内容相同可复用实体，但保留名称、来源以及不同日期/课次的使用记录；同课次的高频访问合并。
- 归属使用首次有效检测时间，不使用迟到的复制成功时间；成功保存后才允许导出。
- 锁定/失败采用有限重试，最长不超过 40 分钟，可先密后疏；提供明确失败状态和手动重试。
- 不把修改跟踪/版本管理当作必做；第一次打开后的留存为基础。
- 不自动清理资料。删除需确认，移入应用可恢复区，允许恢复和另行彻底清理。
- 无账号或 PIN；学校/使用者知情，危险动作二次确认。
- 严格/宽松监测模式可切换，默认宽松。目录、递归、扩展名、进程名称/路径、排除规则和诊断均可配置；PID 不持久写死。
- 自动排除归档本身和已知临时/锁文件；不把 Explorer/dllhost/System 的访问等同于真正打开，也不承诺完美区分预览。

## 5. 时间表、课表与调课

- 分成两个编辑区域：每天共用的时间段定义；按星期编辑的科目/课程启用状态。
- 支持手动编辑、CSV 模板导入导出、应用 JSON 配置导入导出；第一版不做 XLSX 导入或截图识别。
- 每个当天有效课次一张卡片，相同科目多节仍分开，按课表顺序排列。
- 课间资料归下一节课；没有下一节时的边界需要在计划中明确，不跨日期盲猜。
- 卡片右键或卡片标题区域长按调课，只更改当天该课次及其内部资料记录的科目，不更改周课表或其他日期。
- 普通修改周课表不自动重算已保存历史；保持当时课程快照，允许明确纠正归属。
- 未开始的卡片半透明，并显示“这节课还没有上哦”；空卡片保留，不造示例文件。
- 同科目卡片下方提供前/后同科目课次跳转。

## 6. 主页与复制操作

- 主页左右/上下分屏及固定夹/浏览区排列严格按原描述。2026-11-14 实施中用户进一步明确：不放“今日文件”标题或宣传副标题，不增加顶部引导区；主要视图直接分成两半，优先无外边距。
- 两种方向各自记住大分屏比例；内部固定夹/浏览区比例也持久化，初始等分。
- 文件按首次检测/使用时间排列，显示文件名和短时间；其他信息在详情中。
- 单击文件选中，双击打开归档副本，选择圆圈切换多选；文件夹双击进入。
- 鼠标按住移动拖拽；触屏长按文件拖拽，滑动滚动。卡片标题区域长按用于课程菜单，避免与文件拖拽混淆。
- 拖已选项携带全体选中项；拖未选项切换为仅拖该项，遵循问卷明确选择。
- 卡片全选和课程 + 按原需求实现；+ 把课程文件直接复制到当前目录，不自动建立科目子目录。
- 底部悬浮条含“复制全部”和右侧“X 清除”；复制后保留选择，便于继续导出到另一个设备。
- 拖到浏览区/固定区的具体文件夹就复制到该夹；只要求应用内部拖拽。
- 同名冲突弹出批量策略，默认保留两份，支持跳过、明确选择替换及本批次应用全部。
- 目标缺失/不可写时禁用复制并解释，不自动写到另一盘。

## 7. 设备与文件浏览

- 按物理 U 盘区分身份，多个分区共享固定夹分类；固定夹须同时知道对应分区和相对路径，不能只记盘符。
- 允许格式化后当新设备；无法可靠确定身份时不能误套另一设备的固定记录。
- 本地盘也支持固定夹，允许改显示名、排序、移除、失效后重新定位。
- 点击固定夹进入，拖入复制；插入不自动切换，用户点击侧栏才选择；拔出取消当前目标，固定记录保留。
- 右下角常驻安全弹出按钮；本地盘或没有可弹出设备时应禁用并说明，不提供危险弹出系统盘的路径。
- 文件浏览支持进入/上级/前后导航、面包屑/路径输入、刷新和目录变化、列表/网格、名称/类型/大小/时间排序。
- 支持新建夹、重命名、隐藏文件切换、系统打开与 Explorer 定位。
- 浏览侧不做自身多选复制粘贴、移动剪切、网络地址浏览；原始文件绝不因归档/导出而删除。
- 删除优先系统回收站；U 盘不支持时不默默降级为永久删除，需在后续计划中明确保守行为。

## 8. 库与全局搜索

- 库默认全宽网格，按实体资料合并；详情提供使用历史。
- 库中点击驱动器后出现左右分屏：左库、右驱动器浏览；不能切上下分屏。
- 库同样有多选复制悬浮条，不必回主页才能导出。
- 按课次/日期分组可在相应组显示同实体的关联；一个批次不能重复导出同实体。
- 分组：无、年月/日期、科目、课次、文件类型；筛选：科目、日期范围、文件类型、名称；排序：收纳/使用时间双向、名称、大小。
- 全局搜索输入结果浮层，支持触屏/基本键盘选择；Enter 进入库搜索结果并保存原主页状态。
- 默认普通文件名关键词，显式正则开关，匹配文件名；错误就地说明，使用受控无灾难回溯的引擎。第一版不做高级 JS 正则或全文内容索引。
- 格式图标沿用原图标库；图片用真实异步缩略图。Office/PDF 首页缩略图不做。
- 详情包含名称、时间、科目、大小、原/归档路径。默认打开归档副本，不提供原文件打开入口。
- 允许改显示名称、科目/课程；源不可用不影响已归档副本。

## 10. 需要说明的技术边界与拟采用的理解

### 10.1 冻结 C 盘下的自启动（部署条件未决）

Windows 不会因为 D 盘存在 EXE 而自动启动它。普通启动目录、Run 注册表、任务计划和服务的触发配置通常依赖 C 盘/注册表的持久状态。仅把任务指向 D 盘，并不能防止任务配置本身被还原。

可行的正常部署条件包括：
- 经有权限的维护人员临时解除还原保护，配置指向 D 盘的登录任务/启动入口，再保存新的冻结基线；
- 使用已经存在且会被保留的启动机制，而该机制确实支持读取 D 盘上的配置/启动链；
- 在上述条件未确认时手动启动。

不能承诺一个完全没有任何持久触发入口的“纯 D 盘自动启动”办法。开发前期不安装或注册启动项，最终学校部署时再确认可用条件。

### 10.2 单 EXE与 WebView2（环境前提）

CelesVault 的程序/UI可嵌入单 EXE，data目录作为便携持久数据。Tauri Windows UI仍需要 WebView2运行环境；这不是简单复制通用按钮就能消除的依赖。

拟按“单 EXE指 CelesVault程序文件，学校冻结基线中有可用 WebView2”制定前期计划。若学校缺少运行环境，再决定维护时安装或其他运行时分发办法，不现在自行安装。

### 10.3 浏览器预览（待确认解释，不改变最终验收）

拟理解为：我可以使用仅前端的浏览器预览服务/页面，检查布局与交互；不启动Rust/Tauri，不运行本地check/build/test。你运行包含后端的完整dev。

普通浏览器无法直接调用任意 Windows驱动器、ETW和托盘。因此预览数据/平台适配要显式区分；仅开发预览可用标注的测试数据，Native交付必须接真实数据。不会将预览模式按钮模拟成功当作真实复制通过。

### 10.4 建议的少量边界默认值（可在确认时纠正）

- 课间的“下一节”只在当天查找下一节启用课程；放学后/无课日没有下一节时放未归类，不跨午夜盲归下一天。
- 未开始的卡片即使已有准备资料，仍可选择和复制；半透明不是禁用。
- 普通课表编辑不更改历史；显式当天卡片调课是用户批准的例外，更新该课次已有记录。
- 库进入时默认全宽，即使主页之前有目标；显式点驱动器才展开右侧，保留主页自身浏览状态。计划中补上关闭库浏览分屏的入口。
- 安全弹出在复制/归档正在使用该物理设备时不能强行执行，应提示等待/取消并安全释放；不只凭当前盘符行动。
- 不支持系统回收站的 U 盘，第一版删除不直接永久执行。
- 日期/课次实体目录和内容去重必须分开处理。后续计划明确实体位置与多课次关联，不能为了去重把后来的使用记录丢掉，也不能暗中采用会把原文件和归档绑定的硬链接。

以上不是额外的功能范围；它们用于避免实现时产生隐含矛盾。理解确认后，再制定阶段顺序、文件结构、数据模型、组件迁移清单和验收办法。
