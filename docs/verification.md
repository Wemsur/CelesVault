## 用户 Native 验证步骤

先停掉 Browser pane 的仅前端服务，避免占用 8006 端口。由你主动打开管理员终端，在 CelesVault 运行：

```bash
pnpm run app:dev
```

待确认：

- [ ] Tauri/Rust 能正常编译并启动，窗口名为 CelesVault。
- [ ] 系统没有安装新服务/自启动/默认关联；非管理员启动明确失败，未伪装运行。
- [ ] 顶部最小化、最大化/还原是真实窗口动作，控件状态同步。
- [ ] 第一次点自绘关闭显示托盘说明，确认后窗口隐藏；托盘打开恢复窗口。
- [ ] Alt+F4/系统关闭也隐藏到托盘；托盘退出结束进程。
- [ ] 再次启动不产生第二个实例，恢复现有窗口。
- [ ] 托盘暂停项在采集尚未接入时禁用，界面始终说明未监测。
- [ ] 主页/库路由、原设置弹窗、取消/未应用确认没有运行时错误。
- [ ] 没有正式归档文件写入；界面设置当前仅本次会话。

若管理员 dev 报 740 或 Windows 启动失败，提供终端原文，不通过降低 UAC/执行策略来解决。WebView2、Rust/MSVC 环境由你确认，助手不擅自安装。
