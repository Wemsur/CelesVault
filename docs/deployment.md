# 部署边界（阶段 1）

此文件不是正式部署完成记录。

- 第一版整个进程以管理员运行，manifest 要求 `requireAdministrator`，运行时核对 Token。
- **完整 dev 请在你主动打开的管理员终端中运行 `pnpm run app:dev`。** 非管理员终端可能因为 Windows 拒绝直接启动需提权 EXE 而报错误 740；这不是已经验证的正常启动路径。应用不擅自修改系统启动项或账号权限。
- WebView2 是 Tauri Windows UI 的运行环境前提；源码与单 EXE 不等于无需 WebView2。
- EXE同级data为首次目录选择默认建议；选定后SQLite、监测设置、资料与重试任务均放持久根。程序同级celesvault-location.json保存定位，学校最终选择不受还原影响的D盘。阶段2代码已接入，Native仍未验证。
- 普通关闭隐藏到托盘，打开恢复、退出先停止和回收后台任务。阶段2接暂停/恢复；未配置持久目录时不启动监测并禁用暂停。程序/托盘/安装器引用用户新图标。
- 本轮没有编写/触发最终发布工作流。阶段7只支持手动 workflow_dispatch、Windows x64、便携 EXE与 NSIS；不自动发布、注册关联或卸载归档数据。
- 自启动须经正常维护更新冻结基线或有现成持久启动链；D盘有EXE不会自动启动。不尝试绕过冰点，不在开发机注册。
