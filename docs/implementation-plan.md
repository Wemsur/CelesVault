- 校验结果分为：我完成的只读/浏览器验证、用户 Native dev反馈、用户手动 CI结果。未验证明确标注，不使用“测试通过”代替事实。

## 二、推荐架构与工程边界

采用独立 Vue 3 + TypeScript + Vite + Tailwind 3.4 前端，Vue Router，轻量 Pinia 状态；Tauri 2 宿主；可复用 Rust core。首版无需服务器、Postgres或独立后台服务。

```text
CelesVault/
  package.json / pnpm-workspace.yaml / Cargo.toml
  src/
    App.vue / main.ts / router/
    layouts/                 # 相连顶栏、左栏、主内容壳
    features/
      home/ library/ settings/ file-browser/
    components/              # 用原控件组合的业务视图
    stores/                  # 查询状态、选择、浏览目标、设置草稿
    platform/                # 统一能力契约，native / preview适配
    vendor/celestial/
      ui/ assets/ styles/ adapters/ provenance/
  src-tauri/
    src/commands/ tray/ window/ lib.rs
    capabilities/ tauri.conf.json
  crates/vault-core/
    storage/ archive/ capture/ timetable/ devices/ fs_jobs/
  tools/wps-probe/            # 保留现有独立诊断工具
  docs/
    requirements.md implementation-plan.md architecture.md
    decisions.md component-provenance.md verification.md
    deployment.md history/
  .github/workflows/windows-build.yml
```

这是职责边界，不要求为每个小函数建立文件。Rust core不依赖 Vue/Tauri窗口；Tauri只接命令、事件、窗口、托盘。原控件与平台适配分离，不把 Tauri调用写进通用业务组件。

直接复制必要原源文件和闭包，配置精简出口/别名，不复制原库总 barrel及全部业务：

- `../CelestialLauncher/packages/ui/src/components/base/{Card,Checkbox,Toggle}.vue`、`base/buttons/{ButtonFrame,Button,IconButton}.vue`及其 types。
- `base/inputs/{Input,InputFrame,InputClearButton}.vue`及types。
- `modal/{NewModal,TabbedModal,ConfirmModal}.vue`；配套 modal-stack、scroll-indicator、truncate、anchored-teleport、必要DI叶子接口。
- 下拉/菜单优先原 DropdownSelect、Combobox、ContextMenu、TeleportOverflowMenu及button-menu闭包；复杂 MultiSelect只在实际业务需要时带入。
- 原变量/normalize/reset/defaults/accessibility/classes.scss、Tailwind preset、原 UI utilities和 light-sense规则；只抽取必要 Launcher全局规则，不把整个 App全局样式套进来。
- 原 SVG、Celestial占位logo及所需原导出名。主题在 html首帧设 customdark-mode和`--brand-hue:38`，覆盖body/teleport。
- 原 Inter版本/字重做离线资源化并保留字体许可，不在离线大屏运行时从CDN取字体。遇下载问题先沟通，不偷换字体。
- 接口级适配静态中文文案、Markdown安全渲染、窗口动作、主题。**完全删除多语言/i18n依赖**：原组件的 useVIntl/formatMessage/MessageDescriptor 改为普通中文字符串、静态文案常量和业务分类ID，不保留翻译 Provider 壳，不引入 vue-i18n、intl-messageformat、语言包或语言设置。必要修改仅限接口与文案，视觉/交互仍复用原组件；不搬账号、API-client、广告、支付、Three/Ace。

### 2.2 Native / 浏览器预览

前端通过同一 typed PlatformClient访问窗口、目录、驱动器、库查询、任务和设置。Native接真实 Tauri命令/事件；浏览器接明确标注的 PreviewAdapter。

浏览器只能验证视觉和交互，测试数据不写入正式data，复制/弹出/监测结果不得伪装为真实系统成功。原组件保持相同，只有平台数据源替换。Native环境不能静默退回预览模式。

### 2.3 持久数据

默认 EXE同级 `data/`，首次选择器默认指向此处；必要的data定位信息也保存在EXE同级持久区域。归档路径和固定夹内部路径尽量相对化，使便携目录搬移可恢复。应用关键配置、SQLite、课表、缓存、恢复区均在data，不以localStorage/AppData为唯一来源。

推荐 SQLite作为元数据与迁移版本存储，普通文件作为资料实体；数据库不能与文件完成状态脱节。

- **资料实体**：内容摘要、大小、类型、显示名、保存相对路径、状态/删除标记。
- **课程使用记录**：资料ID、课次ID、首次检测时间、来源/原名；同课次同实体合并，来源别名可保留。
- **捕获任务**：源身份/路径、原事件时间、状态、重试截止和失败原因。
- **课表**：科目、共用时间段、星期课程启用、当天覆盖、历史课次快照。
- **设备/分区/固定夹**：物理身份、分区/卷身份和代际、当前挂载、相对路径、别名和顺序。
- **设置/视图**：监测规则、两种主页比例、内部比例、库左右比例、缩放/窗口/选择相关行为。

实体保存为 `data/archive/日期/课次序号-科目/安全原名`。相同内容后续课次只新增使用记录，复用首次实体；**因此不保证每个后续日期目录都再有一份同内容文件**，UI按记录展示历史。科目/显示名修改默认只改元数据，不悄悄移动文件。不得把原文件与归档硬链接。

为保护内容摘要和去重实体，归档主副本按只读资料管理；需要编辑时另存新文件，原文件属性不改。检测外部篡改/缺失时标记异常，不继续盲目复用错误摘要。此行为在界面/文档明确说明。

- 独立.git不能依赖上层objects alternates；现有0.1.1和文档保留为后续快照，不丢未提交修改。上层原历史和其他暂存不改；解除父仓库对CelesVault的旧跟踪如有需要，另行说明，不混入迁移。
- 建立新功能分支，不在默认分支直接做功能提交，不创建远程仓库/推送。
- 固化GPL/第三方来源、禁止本地自动构建检查、无共同作者署名、只手动发布等工程约束。
- 将已确认需求稿更新为基线，保存本计划、组件来源清单和验证记录入口；保留现有diagnostic工具。

**验收：**用户文件/诊断历史可找到；独立git只含CelesVault；上层其他项目暂存未变。Git安全核对属于只读/迁移验证，不是运行构建。

### 阶段 2：最小真实收纳与复制闭环（优先级最高）

- 从 `tools/wps-probe/src/etw.rs` 的 Collector/TraceSession、`windows.rs`进程/设备路径映射、`filter.rs`范围判定提取可复用采集模块；不把控制台打印、临时样本和大量原始日志当正式后台。
- 按扩展名/来源/归档排除、进程路径/名称筛选，PID动态关联。宽松模式接受配置的WPS安装路径内辅助来源；严格模式只接受配置主程序来源。两者都不是100%预览/人工打开识别。
- 有界队列、同源同课次合并；回调不做复制/摘要/数据库重活。未知进程、未解析事件、队列丢弃纳入健康状态。
- 创建捕获任务后只读源，流式复制到自己的staging并计算保存副本摘要；检查复制期间源是否变化，原文件不改。
- 资料成功落盘后才置available；数据库记录先有任务意图，文件与事务中断可恢复。相同摘要复用实体并追加课次记录。
- 重试最长40分钟，采用先密后疏；源设备换成另一个盘不能按同盘符误读，超时失败可主动重试。
- 暂无课表时使用明确的未归类卡片，不用假课表替代。为后面阶段提供最小时间/课次接口。
- 复用Sigma `dir_reader`、复制任务/冲突/取消的设计：Rust负责真实目录与复制；修正路径/身份/有界进度，不带移动或网络功能。
- 最小主页呈现真实已收纳条目及目标目录、复制动作/进度，形成实际可用闭环。不会在数据未保存时让导出成功。

**验收：**用户dev内打开真实DOCX/PDF/JPG/PPT并查看留存；拔原源盘后归档仍能打开与复制；重名不会覆盖；源锁/失败有状态。Excel未补测不等于删功能，状态明确标未验证。

### 阶段 3：完整主页与设备固定夹

- 完成左右/上下两种布局、每种及内部比例保存、最小尺寸。
- 课程卡片来自真实课次接口：按顺序、空/未来态、卡片全选、课程+、文件网格/短时间/两行省略、同科目前后跳转。
- 选择模型按资料ID；复制后保留，浮条含复制全部/X清除。课程+直接复制到当前目录，不建课程子夹。
- 鼠标阈值拖拽、触屏文件长按拖拽/滑动滚动；卡片标题长按菜单。拖未选项改为单项。每次操作冻结selection/目标快照，避免异步时写错目标。
- 建立物理设备识别与分区关联：优先硬件序列/PNP/磁盘标识，卷/分区身份作辅助及格式化代际；运行时盘符/磁盘编号不充当永久ID。不可靠时提示重新关联，不伪造绝对唯一。
- 侧栏可导航分区/盘根；同一物理U盘共享固定夹列表，每项含对应卷与相对路径。支持别名/排序/移除/失效定位；本地盘同样可固定。
- 不自动切盘，拔盘清目标但记忆保留。固定夹点击进入、拖入复制。
- 完整复制冲突modal：保留两份/跳过/明确替换、本批次全部；再次校验目标已存在文件未发生不受批准的变化。

**验收：**用户在dev测试真实目录/多选/课程+、同资料第二次复制、U盘改盘符和插拔；我在浏览器测试两种排布/长名/触控模拟，手机远程与真实触屏由用户最终验证。

### 阶段 4：多页设置与课表

- 按原TabbedModal布局完成存储、监测、课表、界面行为、诊断、关于；保存/取消/未保存状态，不绑定账号。
- 时间段编辑：每日共用，课程/非课程、开始结束、顺序与有效性校验。
- 星期课程编辑：科目/节次、启用开关；参考ClassIsland `TimeLayout/TimeLayoutItem/ClassPlan`，不直接引入.NET。
- 当天覆盖与历史课次快照：普通课表修改不重算历史；当天卡片调课事务性更新该课次和关联记录。
- 课间归当天下一节启用课，没有下一节/无课日为未归类；不跨日期猜课。首次事件时间决定归属，重试成功不换课。
- CSV/JSON模板导入导出、错误预览与确认；配置导出不包含资料实体，也不被称为完整灾备。
- 监测规则、两模式、排除、目录、缩放、窗口状态和诊断落data；仅托盘颜色安静提示，详情主动打开。

**验收：**用户用真实课表测试取消当天课、同科目两节、课间、跨午夜、当天调课与重启；我只做浏览器表单/未保存/空态验证。

### 阶段 5：库、搜索和库侧浏览

- 复用Celestial主页列表/卡片的视觉和控件组织，但数据是归档实体/使用记录。
- 网格/列表、无/日期/科目/课次/类型分组、已选筛选和时间/名称/大小排序；元数据查询分页/虚拟化，不一次渲染1万DOM。
- 全局名字搜索浮层与Enter进入库；显式正则、受控Rust regex、就地语法错误、不全文扫描。重名别名也可匹配，不把未筛中的实体重复导出。
- 默认库全宽；显式选盘展开左库右浏览，固定左右，提供收起入口。主页和库保存各自视图状态。
- 库多选和复制悬浮条，真实TargetContext；目标未选择不可写时禁用，不使用看不见的隐含目标。

**验收：**我做浏览器结果浮层、列表/网格、长名、弹窗状态；用户验证真实库查询、源盘移除后的打开/导出、跨课次去重和非法正则。

### 阶段 6：安全与可靠性收口

- 应用回收区与恢复、关联记录一致性，永久清理必须确认，不自动清档；浏览侧普通文件删除不偷换成U盘永久删除。
- 补全新建夹/重命名/隐藏开关、主动刷新/目录watch、Explorer定位/系统打开。通用浏览操作不得直接改坏data内部实体/数据库。
- 复制/归档进度、失败/取消/拔盘、应用重启的任务与staging恢复。任何目标身份变化不自动换设备继续写。
- 右下角安全弹出：以物理设备和所有卷为边界；有活动任务/句柄时不能强制成功，正确释放/刷新后调用Windows接口；非可弹出设备禁用。
- 隐藏后台、窗口显示/关闭/退出、暂停/恢复、单实例和错误状态；不抢焦点。
- 对1万元数据、连续典型WPS使用、图片缓存、反复分屏/设备切换提出并记录实测：空闲后台平均CPU目标约1–2%、进程组内存约350MB内、常见查询/操作1秒内有反馈、典型可读小文件几秒内可用。均为目标，不是已测承诺；以8GB设备用户反馈调整。
- 编写回归用例/操作清单，但不在本机自行执行测试/check；用户或明确手动CI执行，报告未验证项。

**验收：**用户本地完成故障矩阵/真实触控和资源占用反馈；未过安全/数据一致性门槛不能宣称正式可用。
