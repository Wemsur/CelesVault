# 阶段 2 · 最小真实收纳与复制

2026-11-15 用户在正式图标替换后授权继续下一步。当前阶段2代码接入，**Native编译与真实文件操作仍未验证**。阶段1的窗口/托盘验证欠项继续保留，不以新代码替代验收。

## 当前代码链路

1. 用户在设置中选择持久目录；程序同级 `data` 为默认建议，不自动扫描或创建正式资料库。
2. 选定后初始化 data 内 SQLite 与资料目录。程序同级 `celesvault-location.json` 只保存持久目录定位，下次启动读取；保存失败明确说明，不称为持久化成功。
3. Windows ETW 由独立 `CelesVault-Capture-*` 会话采集，复用诊断工具的路径/进程关联代码；PID动态关联、不写死。
4. 默认来源桌面/下载/D盘/已挂载USB，扩展名含Word/PPT/Excel/PDF/图片；只接配置的WPS主程序或宽松模式允许的WPS安装目录辅助程序。不直接接受Explorer/System等访问。
5. 有界事件/候选队列，回调不做摘要/复制/数据库工作。创建意图后独立归档线程流式读源，计算保存副本SHA256，检查源身份/大小/修改时间变化。
6. 自有staging同步后保存意图，用持有的文件/目录句柄不覆盖发布，再提交available。已归档主副本只读，原文件属性不改。
7. 同内容复用实体、每日未分类使用记录合并；原事件时间决定日期，不按重试完成时间。无课表时明确未分类，不生成假课表。
8. 最长40分钟先密后疏重试，失败可手动重试；原卷/文件身份变化不按同盘符误读。启动按已知任务路径恢复，不扫描全系统。
9. 前端每2秒读取状态/真实今日记录/驱动器/复制进度。目录只本地盘，不跟随junction，不暴露data内部。
10. 导出仅前端资料ID，Rust验证已归档实体，持有摘要验证租约交接到复制线程；不能从JS传任意源路径。目标目录/卷身份在操作中固定，复制后保留选择。
11. 同名默认保留两份，可跳过；明确替换与完整批次冲突预览在阶段3接入。取消只删除本任务自有暂存，不回滚已完成副本、不删原文件。
12. 托盘打开/暂停恢复/退出；错误状态变色而不抢焦点。退出请求取消同步I/O、停止自身ETW、等待后台join，不强杀线程或声称立即取消。

## 实现限制（仍属阶段范围）

- 课表、按课程完整卡片、物理USB固定夹/多分区代际、内部拖拽、库查询、安全弹出与恢复区在后续阶段接入。
- 目录当前简明列表，200项/页，上限10000；导出批次最多1000份，单任务，保留32个结束任务。复制临时残留只隐藏，完整可信恢复在阶段6收口。
- 设置中监测规则真实保存data；界面方向/缩放目前仅会话状态，完整设置持久化在阶段4。
- 图片当前类型图标，真实异步缩略图及缓存后续阶段接入；没有Office/PDF首页渲染。
- 已有归档的正常列表校验采用有界文件指纹缓存，打开/导出/去重始终重新验证摘要；不能以只读属性保证无人改动。
- 故障、Win32 API、SQLite事务、设备拔盘取消的实际行为需你的Native测试，当前只完成静态源码核对和前端观察。

## 用户运行与验收

在管理员终端运行 `pnpm run app:dev`。助手没有运行本地Cargo/构建/check/test。

- [ ] 首次窗口未配置，选择一个测试持久目录后显示真实ETW状态；取消选择不初始化。
- [ ] 在来源范围中用WPS打开DOCX/PDF/JPG/PPT/Excel；记录可用后检查原文件未变，副本存在且只读。
- [ ] 同名不同内容不覆盖；同内容高频重复合并；跨日期增加使用记录。
- [ ] 锁文件或暂不可读任务有等待/失败/重试状态，最长40分钟；首事件日期不被重试改掉。
- [ ] 拔原源盘后归档仍可打开、导出；另一个盘占相同盘符不能误读。
- [ ] 点击真实驱动器、双击目录或输入本地路径可浏览；网络路径/junction/data内部被拒绝。
- [ ] 选择资料导出到当前目录，同名保留两份/跳过，原文件不删除、归档不改、选择保留。
- [ ] 复制中拔目标盘/取消任务，不自动改写另一设备；仅任务自己的临时文件可清理。
- [ ] 暂停后不接受新候选，已接受任务仍完成；恢复监测、关闭托盘、退出停止独立ETW。
- [ ] 重启恢复同一持久目录、意图与已知staging；异常/缺失资料不可继续打开或导出。
- [ ] EXE/任务栏/托盘/NSIS使用新图标，左上角仅文字。

遇编译或权限错误请反馈终端原文，不通过降低UAC/执行策略解决。WebView2仍是环境前提，助手不安装。
