# 已确认决策

| 决策 | 采用 | 理由/边界 |
|---|---|---|
| 连续推进 | 用户2026-11-15授权连续实施阶段3–7 | 编码与Native/CI/学校验收分开；2026-11-21追加自适应课程卡片、主题和背景，最新显式命令优先 |
| 独立 Git | 子树历史重建，父仓库不改 | 原诊断提交元数据保留；父跟踪尚未解除 |
| 语言 | 全中文、普通字符串 | 无 i18n、语言包、翻译 Provider |
| 视觉 | Celestial 原控件与 customdark hue38 | 原间距、圆角、字体与交互；不另建设计系统 |
| 字体 | 同版 Inter 3.19 五字重离线 | 保留 OFL，中文使用原字体回退 |
| 框架 | Vue3/Vite7/Tailwind3.4/Tauri2 | 独立轻量工程，无原 monorepo 服务 |
| Native | 整个应用管理员、关闭到托盘 | 不安装服务/自启动；监测未接入就明确未接入 |
| 浏览器 | 仅开发 PreviewAdapter | 无真实系统成功声明；Native 不回退 |
| 构建验证 | 用户运行 | 助手仅只读分析和前端浏览器观察 |
| 新提交 | 无共同作者署名 | 用户2026-11-21要求每次修改完成直接本地提交，保存明确标注未验收的进度快照；不附Co-Authored-By，推送/发布仍需明确授权 |
| 数据根 | EXE同级data默认建议，首次用户选择 | 监测规则/SQLite/任务与资料在data，程序同级定位文件恢复 |
| 网络故障 | 给地址/错误，不手动盲重试 | 项目依赖配置关闭自动 fetch 重试 |
