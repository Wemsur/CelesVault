# 手机局域网触屏演示

## 启动与访问

手机与电脑连接同一可信局域网。电脑在项目目录运行：

```powershell
pnpm run web:dev
```

该命令监听0.0.0.0:8006；手机打开 `http://电脑的局域网IPv4:8006/`。IP以电脑当前Wi-Fi/以太网为准，Vite启动会打印Network地址。手机127.0.0.1指手机自身，不能用Vite proxy替代网络转发。不需要ADB。

不启动或修改系统防火墙；若访问不到，核对两端Wi-Fi、访客网络/AP隔离，以及用户是否允许Node.js在Windows专用网络通信。不要对公网开放开发服务。Vite保留strictPort和默认Host校验，限制文件服务根并禁止.env/.git/data/target/持久目录定位文件；未增加代理或Native HTTP接口。开发服务会提供项目源码，测试后在启动终端Ctrl+C停止。

完整Tauri的beforeDevCommand改用 `web:dev:local`，继续仅127.0.0.1:8006；不要与web:dev同时争用8006。Native不会读取演示适配器，也不会因出错回退演示。

## 演示数据与支持的操作

DEV普通浏览器使用内存演示，常驻橙色提示“非真实资料，所有操作刷新重置”。每个手机/标签页独立，不写localStorage或正式data。

- 9节虚构课程，包含空课、单文件、多行溢出、长名称、失败和等待状态；库约86项。
- 虚构P盘，根下55个目录和35个文件，子目录28个文件，18个初始固定夹；首次自动进入演示P盘。
- 两方向课程/文件/库/目录/固定区触屏滚动、长按归档拖放、目录文件夹长按拖入固定区，以及固定/取消固定。
- 演示复制仅在Map数组中添加目录项；通知标明“演示、未写磁盘”，可测试重复冲突。演示回收/恢复/失败移除与重试也只改内存。
- 外观、缩放、通知与布局可“应用到演示”，刷新即重置。手机窄屏隐藏桌面窗口控件，搜索在顶栏第二行。
- 关键词搜索/分组筛选可观察。正则教学和图标可测试；实际Rust正则不在浏览器中模拟，开启查询明确报告不支持，不换成JS正则。
- 真实监测、进程清理、持久目录选择、系统打开/定位、安全弹出、真实文件创建/改名/删除、配置导入导出等仍明确不可用。

HTTP局域网通常不是secure context：演示ID不依赖crypto.randomUUID；图片选取和WebGL仍取决于手机浏览器支持。原图只由用户显式选取，转换副本留内存，不上传电脑。手机演示不是Windows ETW、文件安全、设备或原生触屏验收。

## 触屏复验

建议先横屏，测试左右分屏上下划、上下分屏左右划；分别从课程标题、文件、空白、按钮附近起手。文件多时先测试卡内滚动，随后到最顶/底等待轮询，确认不跳走。再测试库、目录和固定区短划，以及450ms长按拖动与滑出目标取消。

“设置 → 数据与诊断”可读触点能力、鼠标输入、手势计数和实际滚动累计。如果仍不可滚动，请反馈手机浏览器、起手区域、分屏方向与计数变化。刷新重置演示和诊断。
