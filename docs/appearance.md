# 自适应课程卡片与外观设置

2026-11-21用户明确追加此范围，覆盖原计划将背景后置的安排。源码已实现，**前端运行与Native尚未验收**；不把本地提交当验证通过。

## 课程卡片

- 左右分屏：课程从上到下；空课仅保留标题、空态、必要操作。非空卡随文件行数增长，文件区最多约三行（每行约11.5rem，随界面缩放），同时受视口高度限制，超出内部滚动。
- 上下分屏：课程从左到右；卡片使用可用高度，根据文件数量和可容纳行数增宽，最多约三列文件宽度；空课较窄。标题/选择按钮保留最小可用宽度。
- 首末卡片分别按实际尺寸补内部居中空间；保留中心吸附、前后同科目跳转、鼠标滚轮与触屏手势。轮询文件数量变化重新测量，普通内容刷新不跳到别的课。

## 外观与持久化

设置增加“外观”页，主题预览卡复制自Celestial原组件。保留原字体/控件、customdark及customlight token，提供浅色、深色和跟随系统，色相默认38、范围0–360。旧配置无appearance时使用深色、背景关闭；保存/取消沿用原草稿流程，取消恢复主题、背景与缩放。

外观存于AppSettings.appearance，随选定data中的SQLite配置保存，配置格式仍v1、数据库schema不变；新增字段有默认值且按范围验证。不存在独立浏览器localStorage真源。首次未选data只能预览，不能报告保存成功。配置导出包含图片显示副本，仍受整份1MiB限制。

## 背景与参数

背景位于壳后、不接管触摸或点击；关闭时保持原背景。沿用Celestial global.scss的逆向外围遮罩：主区域保留左上圆角，以零模糊、250px扩散的box-shadow沿圆角外缘填满顶栏/侧栏及圆角缺口，顶栏/侧栏本身透明，不单独叠色。深色外围surface-3为65%、主区surface-1为48%；浅色沿用variables.scss的覆盖，分别55%/38%。外壳和目录浏览底层透明，避免主区重复叠加；外围网格不截获事件，顶栏、侧栏及主区显式恢复交互。菜单、弹窗及资料卡片保留清晰主题表面。

主页顶栏只保留一个分屏切换按钮，图标和提示表示下一种布局：当前左右时显示上下，当前上下时显示左右；点击沿用现有视图设置保存，两种布局各自的分屏比例保留。库页面仍隐藏该按钮。

参考本地bilibili-margin的源码提供13款：极光、丝绸、网格渐变、颗粒、冰蓝、丝缎、烟霞、流萤、流沙、天光、弥散、流光（WebGL版）、汇流。流光使用参考已有WebGL版本，不引入vgpu/WebGPU依赖。

- 每款独立保存精细度25–100%、速度0–3倍、强度0–100%、15/30/60帧上限；默认50%、1倍、60%强度、30帧。精细度受最大1280px宽及约100万像素GL缓冲预算限制。
- Builder类（丝缎、烟霞、流萤、流沙、天光、弥散）支持纹理尺度0.5–3倍及颗粒0–3倍；纹理细节仅为真正读取该参数的烟霞、流萤显示。
- 汇流线路20–160条及点击冲击波开关，冲击波同时最多8个。精细度影响Canvas像素密度。
- 隐藏页/窗口和系统减少动态效果停止动画；检测软件渲染时只绘静态帧。只存在一个当前背景渲染实例，切换和卸载释放资源；不承诺未经测量的CPU/GPU预算。
- 图形上下文或WebGL不可用在外观页显示中文状态，不影响正常应用操作，不将渲染失败记成成功。

本地图片支持PNG/JPEG/WebP，输入≤12MiB、≤3200万像素、单边≤16384；最长边缩至1600，转换为≤320KiB JPEG显示副本（透明区域填浅灰），原图不修改。可调完整显示/填满裁切、强度、0–30px模糊。图片随配置保存，不依赖外部原图路径；更换data不自动搬迁旧配置。超限、解码或存储失败明确报错。
